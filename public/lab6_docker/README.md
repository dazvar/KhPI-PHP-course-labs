# Лабораторна робота № 6 - Система авторизації та реєстрації

## Опис проекту
Система авторизації та реєстрації користувачів на PHP з використанням MySQL, розгорнута в Docker контейнерах.

## Технології
- **PHP 8.1** - серверна мова програмування
- **MySQL 5.7** - база даних
- **Apache** - веб-сервер
- **Docker & Docker Compose** - контейнеризація
- **phpMyAdmin** - веб-інтерфейс для управління БД

## Структура проекту
```
lab6_docker/
├── docker-compose.yml      # Конфігурація Docker контейнерів
├── config.php             # Підключення до БД та допоміжні функції
├── create_table.sql       # SQL скрипт для створення таблиці
├── dump.sql              # Дамп бази даних
├── index.php             # Головна сторінка
├── register.html         # Форма реєстрації
├── register.php          # Обробка реєстрації
├── login.html            # Форма авторизації
├── login.php             # Обробка авторизації
├── welcome.php           # Захищена сторінка
├── logout.php            # Вихід з системи
├── test-db.php           # Тест підключення до БД
└── README.md             # Документація
```

## Встановлення та запуск

### 1. Запуск Docker контейнерів
```bash
docker-compose up -d
```

### 2. Створення таблиці в базі даних
Після запуску контейнерів, виконайте SQL скрипт для створення таблиці:
```bash
docker exec -i lab6_docker_mysql_1 mysql -uroot -proot users_db < create_table.sql
```

### 3. Доступ до додатку
- **Головна сторінка**: http://localhost:8080
- **phpMyAdmin**: http://localhost:8082
- **MySQL**: localhost:3306

## Функціонал системи

### Реєстрація користувачів
- Валідація вхідних даних
- Перевірка унікальності імені користувача та email
- Хешування паролів за допомогою MD5
- Використання prepared statements для безпеки

### Авторизація
- Перевірка імені користувача та пароля
- Збереження сесії користувача
- Перенаправлення на захищені сторінки

### Захищені сторінки
- Перевірка авторизації через сесії
- Відображення інформації про користувача
- Можливість виходу з системи

## Тестові дані
Система містить тестові користувачі:
- **Логін**: admin | **Пароль**: password123
- **Логін**: testuser | **Пароль**: password123  
- **Логін**: demo | **Пароль**: password123

## Структура бази даних

### Таблиця `users`
| Поле | Тип | Опис |
|------|-----|------|
| id | INT AUTO_INCREMENT | Первинний ключ |
| username | VARCHAR(50) UNIQUE | Ім'я користувача |
| email | VARCHAR(100) UNIQUE | Електронна пошта |
| password | VARCHAR(255) | Хешований пароль |
| created_at | TIMESTAMP | Дата створення |

## Команди Docker

### Запуск
```bash
docker-compose up -d
```

### Зупинка
```bash
docker-compose down
```

### Перегляд логів
```bash
docker-compose logs -f
```

### Підключення до MySQL
```bash
docker exec -it lab6_docker_mysql_1 mysql -uroot -proot
```
